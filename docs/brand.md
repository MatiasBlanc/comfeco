# COMFECO — Brand Guidelines

## Nombre

**COMFECO**

Significado:

**Community Fest and Code**

No escribir normalmente:

- ComFeco
- Comfeco
- COMFECO V2 como nombre principal

La marca es simplemente:

**COMFECO**

---

## Personalidad

COMFECO debe sentirse:

- tech
- juvenil
- cercana
- energética
- comunitaria
- moderna
- latinoamericana
- creativa

Evitar una estética excesivamente:

- corporativa
- SaaS
- institucional
- gaming
- cyberpunk

---

## Identidad visual

La identidad histórica de COMFECO utiliza principalmente:

- morado
- violeta
- magenta
- dorado
- amarillo

El gradiente entre morado y dorado es uno de los recursos visuales principales.

## Tipografía

### Display

**Barlow Condensed**

Usar para:

- headings
- hero
- números
- titulares promocionales

Weights recomendados:

- 700
- 800

### UI / Body

**Barlow**

Usar para:

- body
- inputs
- botones
- labels
- navegación

Weights:

- 400
- 500
- 600

## Logos

Assets recomendados:

```text
public/brand/
├── comfeco-logo-horizontal.png
├── comfeco-wordmark.png
└── comfeco-icon.png
```

### logo-horizontal

Isotipo + COMFECO + tagline.

Uso:

- header
- footer
- piezas institucionales

### wordmark

COMFECO + Community Fest and Code.

Uso:

- espacios horizontales compactos

### icon

Solo isotipo.

Uso:

- favicon
- avatar
- social
- elementos decorativos

---

## Uso del logo

No:

- deformarlo
- rotarlo
- cambiar sus proporciones
- recolorearlo sin necesidad
- agregar sombras fuertes
- recrearlo con CSS
- generar una versión nueva con IA

Preferir siempre los assets oficiales.

---

## Diseño web

La web debe priorizar:

- buen whitespace
- jerarquía clara
- componentes simples
- uso fuerte pero controlado del branding
- buena legibilidad
- responsive

El color no debe reemplazar a la estructura.

---

## Animaciones

Permitidas:

- fade
- translate sutil
- hover
- transitions
- pequeños efectos de glow

Evitar:

- particles
- animaciones constantes
- parallax pesado
- fondos 3D
- scroll hijacking

---

## Regla principal

La web debe sentirse como:

**COMFECO modernizado**

No como:

**una startup genérica que usa morado.**
