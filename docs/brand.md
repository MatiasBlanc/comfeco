# Marca

## Assets

Los archivos maestros están en [`brand/logos/`](../brand/logos/). Las copias preparadas para servir desde la web viven en [`web/public/brand/`](../web/public/brand/).

## Tipografías actuales

- **Lexend 700** para titulares.
- **Poppins 400, 600 y 700** para texto y controles.

Las fuentes usadas por la web están en [`web/public/fonts/`](../web/public/fonts/).

## Paleta actual de la web

- `#2E2E2E` — base oscura.
- `#390F64` — morado profundo.
- `#521E87` — morado de fondo.
- `#69156A` — morado secundario.
- `#8A178C` — acento magenta.
- `#FFD400` — amarillo de acción.
- `#F3E8F4` — texto claro.

## Tono

Directo, energético, cercano y orientado a comunidad. La comunicación debe invitar a aprender, competir y conectar sin sonar corporativa.
