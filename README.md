**Community Fest and Code**

## Desarrollo

```bash
cd web
npm install
npm run dev
```

La app vive en `web/`. En Vercel usa **Root Directory: `web`**.

Antes de publicar, aplica las migraciones de `web/supabase/migrations/` en Supabase.
